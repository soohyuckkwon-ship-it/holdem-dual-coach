# 홀덤 듀얼 코치

텍사스 홀덤에서 상대 액션을 입력하면 두 전문가가 각자 솔버식 액션 빈도를 내고, 서로 반박한 뒤 합의 액션을 추천하는 웹앱입니다.

- **타이트 전문가**: GTO 기준선을 알지만 실전 풀(블러프 적고 콜 많음)에 맞춰 밸류 중심·저분산으로 이탈
- **균형형 전문가**: 솔버 빈도를 기준선으로 혼합 전략, MDF·블로커·사이징 이론
- **합의**: 상대 정보가 없으면 균형형 60%, 콜링스테이션이면 타이트 비중↑, 토너먼트 버블·파이널의 올인 결정이면 ICM(타이트) 비중↑

사이트: https://soohyuckkwon-ship-it.github.io/holdem-dual-coach/
휴대폰 브라우저에서 열고 "홈 화면에 추가"를 하면 앱처럼 설치되고 오프라인에서도 동작합니다.

## 사용법

3~9인 중 인원과 내 자리를 고르고 카드를 넣으면, 플레이해도 되는 핸드인지 먼저 보여 줍니다. 자리별로 폴드·콜·레이즈를 눌러 진행하면 내 차례마다 두 전문가의 빈도가 나오고, 내 액션을 고른 뒤 상대가 다시 레이즈하거나 다음 스트리트에서 벳해도 이어서 대응을 보여 줍니다.

## 무엇을 계산하나

- 7장 핸드 평가, 상대 레인지(포지션·프리플랍 라인·성향)를 스트리트별 액션으로 좁힌 뒤 콤보별 에퀴티 계산
- 프리플랍: 포지션별 오픈/3벳/4벳 차트, 토너먼트 푸시·폴드와 리스틸, 올인 콜은 에퀴티 + ICM 프리미엄
- 포스트플랍: 체크·벳(25~150%)·올인 또는 폴드·콜·레이즈의 EV를 상대 방어 모델(MDF 기반)로 추정해 빈도로 변환

빈도는 이 모델로 근사한 값이며 실제 솔버 출력이 아닙니다. 온라인 리얼머니 게임 도중 보조 도구 사용은 대부분 사이트 약관 위반이므로 복기·학습·홈게임 용도로 쓰세요.

## 개발

```bash
node tools/serve.mjs          # http://localhost:5178 미리보기 (webapp/)
node --test tests/            # 엔진 회귀 테스트
node tools/build.mjs          # webapp/ → docs/ (PWA 포함)
node tools/deploy.mjs         # gh 로그인 계정으로 GitHub Pages 배포
```

소스는 `webapp/`(engine.js 전략 엔진, app.js 화면)이고 `docs/`는 빌드 결과입니다.
